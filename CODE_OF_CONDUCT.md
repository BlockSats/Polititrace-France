# Code de conduite

Le projet accueille les désaccords argumentés, notamment politiques et méthodologiques. Il refuse les attaques personnelles, le harcèlement, la divulgation de données privées, les menaces et les campagnes coordonnées d'intimidation.

## Attendus

- critiquer les méthodes, données et conclusions, pas les personnes ;
- citer les sources ;
- déclarer les conflits d'intérêts pertinents ;
- accepter la correction publique d'une erreur ;
- préserver un espace de contribution accessible à des sensibilités politiques différentes.

## Modération

Les mainteneurs peuvent masquer ou supprimer un contenu hors sujet, injurieux, discriminatoire, diffamatoire ou exposant des données personnelles. Une décision de modération importante doit être documentée autant que possible.

Les signalements de sécurité ou de données personnelles doivent suivre `SECURITY.md` plutôt qu'une issue publique.
