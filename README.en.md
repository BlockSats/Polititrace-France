# PolitiTrace France

PolitiTrace France is an open-source civic observatory for tracing and comparing French political programmes, statements, parliamentary votes, finances and media coverage.

The project starts in 2017 and initially follows four political families: RN/FN, LFI, the presidential centre bloc, and the Socialist Party.

Core rules:

- every material claim must be traceable to evidence;
- deterministic code computes metrics;
- AI output is explicitly labelled and never treated as primary evidence;
- no single ideological score;
- identical measurement rules apply to every political family;
- third-party data remains subject to its original licence.
