# Sécurité

Ne publiez pas de vulnérabilité, secret, jeton, donnée personnelle ou contenu juridiquement sensible dans une issue publique.

Avant l'ouverture officielle du dépôt, les signalements seront traités par un canal privé à définir dans les paramètres GitHub Security Advisories. La présente politique sera complétée avant tout déploiement public.

Les collecteurs doivent respecter des délais raisonnables, identifier le client lorsque pertinent et ne jamais contourner une authentification, une limitation technique ou une mesure de protection.
