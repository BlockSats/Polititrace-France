# ADR 0002 — Code ouvert et données sous provenance

- Statut : accepté
- Date : 2026-08-01

## Décision

Publier le code et la documentation originale sous licence MIT. Ne republier les données tierces que lorsque leurs conditions le permettent ; toujours publier la provenance, les scripts et les schémas.

## Raisons

Une licence permissive réduit la barrière à la contribution. Le caractère open source du logiciel ne transfère pas les droits sur les articles, vidéos ou bases externes.
