# Politique open source

## Engagement

Le cœur de PolitiTrace France doit pouvoir être installé, audité, exécuté et modifié sans dépendre obligatoirement d'un service propriétaire.

## Exigences

- code source public ;
- historique Git public ;
- méthode, schémas et prompts versionnés ;
- installation locale documentée ;
- formats de données ouverts ;
- export complet des résultats ;
- absence de fonctionnalité réservée à une édition fermée ;
- pas de télémétrie cachée ;
- dépendances et modèles accompagnés de leur licence.

## Intelligence artificielle

Les modèles ouverts et exécutables localement sont privilégiés. Un adaptateur vers une API propriétaire peut exister, mais il doit rester optionnel et ne peut devenir l'unique moyen de reproduire un résultat public.

Chaque analyse assistée par IA doit enregistrer au minimum :

- fournisseur et modèle ;
- version ou empreinte connue ;
- licence lorsque disponible ;
- gabarit de prompt ;
- paramètres ;
- documents d'entrée ;
- date d'exécution ;
- contrôle humain réalisé.

## Données

« Open source » s'applique au logiciel. Les données ne sont publiées comme données ouvertes que lorsque leur licence le permet. Le projet publie autant que possible les métadonnées, scripts de collecte, schémas et transformations permettant de reconstruire légalement le corpus.

## Services publics

Tout déploiement officiel du projet doit afficher la version exacte du code et fournir un lien vers le dépôt correspondant.
