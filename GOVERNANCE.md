# Gouvernance

## Phase d'amorçage

Le fondateur assure la maintenance initiale. Les décisions structurantes sont documentées dans `docs/decisions/`.

## Principes

- gouvernance indépendante des partis et médias étudiés ;
- décisions importantes publiques et motivées ;
- séparation entre maintenance technique et validation méthodologique ;
- recherche du consensus, puis décision documentée lorsqu'il n'est pas atteint ;
- possibilité de publier une opinion minoritaire dans une décision méthodologique.

## Rôles futurs

- **mainteneurs techniques** : qualité du code, sécurité, versions ;
- **référents données** : provenance, schémas, licences ;
- **comité méthodologique pluraliste** : indicateurs, biais, protocoles ;
- **modérateurs** : code de conduite et discussions publiques.

## Conflits d'intérêts

Toute personne ayant une responsabilité officielle, rémunérée ou stratégique auprès d'un parti, candidat, média ou groupe de pression étudié doit le déclarer avant de valider une analyse correspondante.

## Modification de la méthodologie

Toute modification qui change l'interprétation d'un indicateur nécessite :

1. une issue publique ;
2. des exemples sur plusieurs familles politiques ;
3. une décision documentée ;
4. un numéro de version méthodologique ;
5. si nécessaire, le recalcul de l'historique.
