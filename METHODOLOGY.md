# Méthodologie — version 0.1

## Objet

Mesurer des faits observables sans transformer automatiquement ces mesures en jugement politique.

## Unités distinctes

Le modèle sépare :

- parti juridique ;
- groupe parlementaire ;
- coalition électorale ;
- candidat ;
- élu ;
- gouvernement ;
- média ;
- document ;
- affirmation ;
- acte politique.

## Hiérarchie des preuves

1. texte officiel, scrutin, compte certifié, décision juridictionnelle ;
2. document original d'un parti ou d'un responsable ;
3. base de recherche ou média avec méthode documentée ;
4. publication publique sur une plateforme ;
5. calcul reproductible du projet ;
6. interprétation humaine ou sortie d'IA.

Les niveaux 5 et 6 ne remplacent jamais la source primaire.

## Comparabilité

- période identique lorsque possible ;
- dénominateurs explicites ;
- poids parlementaire et statut pouvoir/opposition contrôlés ;
- séparation volume brut / taux normalisé ;
- mêmes dictionnaires et modèles pour tous les groupes ;
- tests de sensibilité pour les indicateurs dépendant d'un modèle.

## Programmes et engagements

Un engagement est stocké avec : source, page, date, thème, formulation exacte, bénéficiaires, coût annoncé, échéance, conditions et degré de précision.

Statuts descriptifs possibles : `tenu`, `partiel`, `en_cours`, `abandonne`, `inverse`, `bloque`, `non_evaluable`, `non_applicable`.

## Traitement médiatique

Les métriques initiales sont descriptives : nombre de mentions, temps de parole, invitations, thèmes associés, position dans le contenu, type de cadrage et tonalité estimée.

Une asymétrie mesurée ne prouve pas à elle seule une intention éditoriale. Toute hypothèse causale doit être présentée comme telle.

## Intelligence artificielle

Toute sortie d'IA conserve : modèle, version, prompt ou gabarit, date, documents d'entrée, paramètres pertinents et niveau de confiance. Un échantillon doit être contrôlé humainement avant publication d'un indicateur agrégé.

## Corrections

Une correction publiée indique : ancienne valeur, nouvelle valeur, cause, date et impact éventuel sur les analyses antérieures.
